# LiteReader

> VS Code 风格的轻量级本地代码阅读器 —— 单文件、零依赖、秒开。

纯 C++ 编写的原生 64 位 Windows 程序：一个源文件、一条编译命令，产出不到 1MB 的绿色 exe，常驻内存不到 3MB。打开即看、随开随关，老旧机器、远程桌面、服务器上都不卡。代码着色美观，支持多套深色 / 亮色主题、代码补全与跳转到定义。

---

## 🎯 设计理念

LiteReader 只想做好一件事：**让「看一眼代码」这件事变得毫无负担**。下面所有技术取舍，都是围绕这句话做的。

| 理念 | 落地方式 |
| --- | --- |
| **零依赖** | 纯 Win32 + GDI 全自绘界面（顶部菜单、标签栏、行号区、文件树、查找条、滚动条、补全弹窗），不引入任何 UI 框架或第三方库 |
| **单文件** | 全部逻辑集中于一个 `LiteReader.cpp`，方便整份阅读、随手修改、直接移植 |
| **绿色分发** | 静态链接运行时，产物是单个 exe —— 免安装、免附带 DLL，拷贝即用 |
| **轻量即功能** | 体积 < 1MB、内存 < 3MB、双击即开；资源占用本身就是要交付的能力，而不是代价 |
| **状态无感** | 每个标签以文档快照保存 / 恢复完整编辑状态（文本、光标、滚动、选区、编码、撤销栈），来回切换不丢任何上下文 |
| **阅读优先，编辑够用** | 编辑只做必要能力，但必须做对：按原编码写回（UTF-8 / BOM / UTF-16 / GBK）不破坏文件；操作式撤销历史记录「被替换区间」，撤销 / 重做均为 O(1) 区间替换，比整篇快照省内存，大文件逐字编辑也稳 |
| **观感统一** | 5 套主题整体联动窗口边框、自绘菜单、标签栏与滚动条配色；Win10/11 下借助 DWM 让非客户区一同沉浸深色 |
| **配置即文件** | 设置写入程序同目录的 `LiteReader.ini`，重启即恢复；无注册表、无隐藏目录，删掉就回到初始状态 |

## ✨ 功能一览

- **语法高亮**：C / C++ / C# / Java / SQL / HTML / ASPX / XML / JavaScript / JSON / Python / CSS；HTML/ASPX 中内嵌的 `<script>`（JS）、`<style>`（CSS）与 `<% %>` 服务端块会分别着色
- **彩虹括号 + 配对高亮**：`() [] {}` 按嵌套深度循环配色；SQL 的 `BEGIN/END`、`CASE/END` 以整词栈配对
- **5 套主题**：`One Dark Pro`、`One Light`、`VS Code`、`IntelliJ IDEA`、`极致黑`，一键切换
- **代码补全**（可选，默认关闭）：关键字 / 类型前缀补全、括号配对自动补全、当前文档内函数名补全；候选弹窗随主题配色、不抢焦点
- **跳转到定义**：`F12` 或右键，以启发式打分定位函数 / 变量的定义处并选中
- **文件夹浏览**：左侧资源管理器式文件树，点击文件即在新标签打开
- **多标签 + 单实例**：重复打开文件聚焦到已有标签，`WM_COPYDATA` 保证只有一个窗口
- **查找**：自绘查找条，上一项 / 下一项 / `F3` 重复查找
- **轻量编辑**：编码安全的保存、撤销 / 重做、全选与剪贴板操作
- **终端联动**：右键在 Windows Terminal / PowerShell / cmd 中打开当前文件所在目录，编辑器内的选中文本会自动带入
- **独立图标**：`appicon.ico`（圆角 "LR" 字标）编译进 exe，窗口、任务栏与文件图标一致

## 🚀 编译（Windows）

需要 **MinGW-w64**（建议 GCC 16.x，64 位）。含图标资源的两步构建：

```bash
# 1) 编译图标资源 → appicon.o
windres appicon.rc -O coff -o appicon.o

# 2) 编译主程序（静态链接）→ LiteReader.exe
g++ -std=c++17 -mwindows -municode -O2 -s -static -static-libgcc -static-libstdc++ \
    -o LiteReader.exe appicon.o LiteReader.cpp \
    -lcomctl32 -lcomdlg32 -lshell32 -luser32 -lgdi32 -ladvapi32 -lole32
```

若不需要 exe 图标，跳过第 1 步，直接编译纯 `.cpp`：

```bash
g++ -std=c++17 -mwindows -municode -O2 -s -static -static-libgcc -static-libstdc++ \
    -o LiteReader.exe LiteReader.cpp \
    -lcomctl32 -lcomdlg32 -lshell32 -luser32 -lgdi32 -ladvapi32 -lole32
```

> `-mwindows`：GUI 程序，无控制台窗口；`-municode`：宽字符（Unicode）API；`-O2 -s`：开启优化并剥离符号，进一步减小体积；`-static*`：静态链接运行时，产物可独立运行。

## 📖 使用速览

- **打开**：`Ctrl+O` 打开文件、`Ctrl+Shift+O` 打开文件夹、`Ctrl+T` 新建标签，也可直接把文件拖入窗口；左侧文件树点击即开。
- **编辑与保存**：直接输入即可编辑；`Ctrl+S` 保存（无路径时弹出另存为），修改后标题栏显示 ` *` 标记。
- **撤销 / 重做**：`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。
- **查找**：`Ctrl+F` 打开查找条，回车跳下一项、`Shift+回车` 上一项、`F3` 重复查找、`Esc` 关闭。
- **选择**：拖拽选择，双击单词高亮其全部出现位置，`Ctrl+A` 全选。
- **标签**：`Ctrl+W` 关闭当前标签，`Ctrl+Tab` / `Ctrl+Shift+Tab` 切换；标签右键可关闭左侧 / 右侧 / 其他。
- **外观**：菜单「视图」中切换主题、自动换行、字号、高亮语言（默认按扩展名自动识别）。
- **代码补全**：「视图 → 代码补全」勾选开启（默认关闭）；候选窗 `↑/↓` 选择，`Tab` / `Enter` 确认，`Esc` 取消，也可鼠标点击。
- **跳转到定义**：选中函数名或变量名后按 `F12` 或右键菜单。
- **在命令提示符中打开**：右键以当前文件目录打开终端（Windows Terminal → PowerShell → cmd 按可用性回退）；若编辑器内有选中文本，会自动复制并粘贴到新终端（不提交）。

## 📁 项目结构

```
LiteReader.cpp   # 全部功能实现（单文件）
appicon.rc       # 图标资源脚本
appicon.ico      # 程序图标（由 icon_gen.exe 生成）
LiteReader.ini   # 运行时自动生成，保存主题 / 字号 / 窗口状态等配置
```

## ⚙️ 配置

程序在自身目录生成 `LiteReader.ini`，自动记录主题、字体大小、窗口位置与大小、最大化状态、侧栏宽度、上次打开的文件夹、代码补全开关等设置。无需手动编辑，界面上的每次操作都会写入，重启后自动恢复。
