# LiteReader

VS Code 风格的轻量级本地代码阅读 / 编辑工具。单文件、零运行时依赖、纯 C++ 编写，用 MinGW-w64 `g++` 一条命令即可编译出不足 1MB 的原生 64 位 Windows 程序，进程常驻内存不到 3MB。

适合日常轻量级代码的**阅读与修改**：打开即看、随开随关，不卡顿、不占资源，代码着色美观，支持多套深色 / 亮色主题、代码补全与“跳转到定义”。

---

## ✨ 主要特点

- **轻量化**：单个 C++ 源文件（`LiteReader.cpp`，约 170KB），无第三方依赖，静态链接后生成 **< 1MB** 的可执行文件（含程序图标约 740KB）。
- **低内存占用**：空闲与工作态进程内存 **< 3MB**，老旧机器、远程桌面、服务器上也能流畅运行。
- **极速启动**：纯 Win32 + GDI 自绘界面，无框架、无运行时，双击即开。
- **多套主题**：内置 5 套主题 —— `One Dark Pro`、`One Light`、`VS Code`、`IntelliJ IDEA`、`极致黑`，可一键切换；窗口边框、自绘菜单栏、标签栏、滚动条等整体跟随主题配色（Win10/11 下通过 DWM 沉浸式深色模式着色非客户区）。
- **语法高亮**：支持 C / C++ / C# / Java / SQL / HTML / ASPX / XML / JavaScript / JSON / Python / CSS 等语言的语法着色。
- **彩虹括号 + 括号匹配**：`() [] {}` 按嵌套深度循环配色；SQL 的 `BEGIN/END`、`CASE/END` 以整词栈配对并高亮。
- **混合语言着色**：HTML/ASPX 中的 `<script>`（JS）、`<style>`（CSS）以及 ASPX 的 `<% %>` 服务端块会被正确识别并分别着色。
- **代码补全**（可选，默认关闭）：
  - **关键字 / 类型补全**：依据当前语言关键字表做前缀匹配（大小写不敏感）。
  - **括号配对补全**：输入 `() {} [] < > " '` 自动补出配对字符并把光标置于中间；选中文本时整体包裹；再次输入右配对字符且其后恰为该字符时直接跳过（避免重复插入）。
  - **函数补全**：扫描当前文档内“标识符后紧跟 `(`”的名称去重收集，确认后自动补 `()` 并光标置于中间。
  - 候选列表为自绘弹窗，随主题配色，不抢焦点；`↑/↓` 选择、`Tab/Enter` 确认、`Esc` 取消、点击项确认；已输入前缀高亮，右侧标 `kw`/`fn` 区分类型；补全后光标落在补全词之后（关键字/类型自动补一个空格）。
- **跳转到定义**：右键菜单或 `F12`，启发式打分定位到选中函数 / 变量的定义处（后跟 `(`、前接声明关键字、前接首字母大写词等加权）。
- **多标签 + 单实例**：可同时打开多个文件，重复打开文件会聚焦到已存在的标签；通过 `WM_COPYDATA` 实现单实例。
- **左侧文件夹浏览器**：「打开文件夹」后在左侧像 VS Code 资源管理器一样浏览目录，点击文件即以新标签打开，当前文件高亮显示。
- **查找**：自绘查找条，支持上一项 / 下一项，回车跳转、`Esc` 关闭。
- **轻量编辑**：可直接修改文本并保存，自动识别并按原编码（UTF-8 / UTF-8 BOM / UTF-16 / ANSI-GBK）写回，避免破坏文件编码；支持撤销 / 重做（操作式历史，按文档保存，切换标签无感知）。
- **在终端打开**：右键「在命令提示符中打开」可打开 Windows Terminal → PowerShell → cmd（按可用性回退）；若编辑器内有选中文本，会自动复制到剪贴板并粘贴到新开终端。
- **配置持久化**：主题、字体大小、窗口位置 / 大小 / 最大化状态、侧栏宽度、上次打开的文件夹、是否开启代码补全等都会写入同目录的 `LiteReader.ini`，重启后自动恢复。
- **运行时图标**：程序化超采样绘制的 “LR” 标识，内嵌为 exe 图标资源；可在「文件 → 设为默认打开程序」中把 `.cpp` 等关联为该阅读器（图标即 “LR”）。

## 🚀 编译（Windows）

需要 **MinGW-w64**（建议 GCC 16.x，64 位）。项目目录含图标资源，两步构建：

```bash
# 1) 编译图标资源（生成 appicon.o）
windres appicon.rc -O coff -o appicon.o

# 2) 编译主程序（静态链接，输出 LiteReader.exe）
g++ -std=c++17 -mwindows -municode -O2 -s -static -static-libgcc -static-libstdc++ \
    -o LiteReader.exe appicon.o LiteReader.cpp \
    -lcomctl32 -lcomdlg32 -lshell32 -luser32 -lgdi32 -ladvapi32 -lole32
```

- 若**不需要 exe 图标**，可省略资源步骤，直接用纯 `.cpp` 命令编译：

  ```bash
  g++ -std=c++17 -mwindows -municode -O2 -s -static -static-libgcc -static-libstdc++ \
      -o LiteReader.exe LiteReader.cpp \
      -lcomctl32 -lcomdlg32 -lshell32 -luser32 -lgdi32 -ladvapi32 -lole32
  ```

参数说明：

- `-mwindows`：生成 GUI 程序（无控制台窗口）。
- `-municode`：使用宽字符（Unicode）Windows API。
- `-O2 -s`：开启优化并剥离符号，进一步减小体积。
- `-static` / `-static-libgcc` / `-static-libstdc++`：静态链接运行时，生成的 `LiteReader.exe` 可独立运行，无需额外 DLL。
- 链接库：`ole32`（COM，用于文件夹对话框）、`shell32`/`comdlg32`（文件/文件夹选择）、`gdi32`/`user32`（界面绘制与消息）、`comctl32`（通用控件）。

编译成功后得到 `LiteReader.exe`。注意：本环境构建产物请**直接输出到目标文件名**（`-o LiteReader.exe`），避免使用 `_new` / `.bak` 等中间名，否则可能被清理机制误删。

## 📖 使用说明

### 打开文件 / 文件夹

- **打开文件**：菜单「文件 → 打开」或 `Ctrl+O`，所选文件在新标签中打开。
- **打开文件夹**：菜单「文件 → 打开文件夹...」或 `Ctrl+Shift+O`，在左侧文件树中浏览；点击任意文件即以新标签打开。
- **关闭文件夹**：菜单「文件 → 关闭文件夹」或点击侧栏头部的 `×`。
- **新建标签**：菜单「文件 → 新建标签」或 `Ctrl+T`。
- 也可直接将文件拖入窗口打开。

### 编辑与保存

- 直接输入、退格、删除、回车、Tab 即可编辑。
- **保存**：`Ctrl+S`（无路径时弹出“另存为”）；修改后标题栏会显示 ` *` 标记。
- **撤销 / 重做**：`Ctrl+Z` 撤销；`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。

### 查找

- `Ctrl+F` 打开查找条，输入关键字后：
  - `回车` / 下一项：跳到下一个匹配；
  - `Shift+回车` / 上一项：跳到上一个匹配；
  - `F3`：重复上次查找；
  - `Esc`：关闭查找条。

### 选择

- 鼠标拖拽选择；双击单词高亮该词所有出现位置。
- `Ctrl+A`：全选。
- `Ctrl+C`：复制选中文本（`Ctrl+X` 剪切、`Ctrl+V` 粘贴）。

### 标签管理

- `Ctrl+W`：关闭当前标签。
- `Ctrl+Tab` / `Ctrl+Shift+Tab`：在标签间切换。
- 标签右键：关闭左侧 / 关闭右侧 / 全部关闭保留选中。

### 外观与语言

- **主题**：菜单「视图 → 主题」选择 5 套主题之一（当前主题带勾选）。
- **自动换行**：菜单「视图 → 自动换行」切换。
- **字体大小**：菜单「视图 → 字体 + / 字体 -」调整。
- **语言**：菜单「视图 → 语言」手动指定高亮语言（默认 `自动` 按扩展名识别）。

### 代码补全

- **开关**：菜单「视图 → 代码补全」勾选启用（**默认不开启**）；开关状态持久化到 `LiteReader.ini`。
- 启用后：
  - 输入字母弹出关键字 / 函数候选，输入 `(` `{` `[` `<` `"` `'` 自动配对。
  - 候选弹窗中用 `↑/↓` 选择，`Tab` 或 `Enter` 确认，`Esc` 取消，鼠标点击项确认。
  - 关键字 / 类型补全确认后光标落在补全词之后并自动补一个空格；函数补全确认后光标进入 `()` 内。

### 跳转到定义

- 选中一个函数名或变量名，右键「跳转到定义」或按 `F12`，编辑器会跳转到其定义所在行并选中。
- 定位采用启发式打分（声明关键字、后接 `(`、前接首字母大写词等加权），适用于单文件内的定义查找。

### 在命令提示符中打开

- 右键菜单「在命令提示符中打开」：以当前文件所在目录打开终端（优先 Windows Terminal，回退 PowerShell，再回退 cmd）。
- 若编辑器内有选中文本，会自动复制并粘贴到新开终端（不带回车）。

## ⚙️ 配置文件（LiteReader.ini）

程序在同目录生成 `LiteReader.ini`，持久化以下设置（无需手动编辑，由界面操作自动写入）：

| 配置项 | 说明 |
| --- | --- |
| `theme` | 当前主题索引（0–4） |
| `fontsize` | 字体大小 |
| `x` / `y` / `w` / `h` | 窗口位置与大小 |
| `max` | 是否以最大化启动 |
| `sidebar` | 侧栏宽度 |
| `folder` | 上次打开的文件夹路径（启动时自动重新打开） |
| `autocomplete` | 是否开启代码补全（0/1，默认 0） |

## 🧩 技术说明

- **纯 Win32 + GDI**：界面全部自绘（菜单栏、标签栏、行号区、查找条、左侧文件树、滚动条、补全弹窗），不依赖任何 UI 框架或原生控件，保证零依赖与极小体积。
- **单文件架构**：所有逻辑集中于 `LiteReader.cpp`，方便阅读、修改与移植。
- **全局视图状态模型**：每个标签以 `Doc` 快照保存 / 恢复编辑状态（文本、光标、滚动、选区、编码、撤销 / 重做栈），切换标签无感知。
- **多选编码**：加载时自动识别 UTF-8 / UTF-8 BOM / UTF-16 LE/BE / ANSI(GBK)，保存时按原编码回写。
- **操作式撤销历史**：每次编辑记录“被替换区间 + 删除串 + 插入串”，撤销 / 重做均为 O(1) 区间替换，比整篇快照更省内存，适合大文件逐字编辑。
- **自绘菜单栏**：客户区顶部自绘「文件 / 编辑 / 视图」菜单条并整体跟随主题，绕开经典 Win10 菜单条无法被 DWM 着色的问题。
