# LiteReader

VS Code 风格的轻量级代码编辑器。单文件、零依赖、纯 C++ 编写，用 g++ 一条命令即可编译出不足 1MB 的原生 Windows 程序，进程常驻内存不到 3MB。

适合日常轻量级代码的**阅读与修改**：打开即看、随开随关，不卡顿、不占资源，代码阅读体验美观，支持深色与亮色主题。

---

## ✨ 主要特点

- **轻量化**：单个 C++ 源文件（`LiteReader.cpp`），无任何第三方依赖，静态链接后生成 **< 1MB** 的可执行文件。
- **低内存占用**：空闲与工作态进程内存 **< 3MB**，老旧机器、远程桌面、服务器上也能流畅运行。
- **极速启动**：纯 Win32 + GDI 自绘界面，无框架、无运行时，双击即开。
- **代码高亮**：支持 C / C++ / C# / Java / SQL / HTML / ASPX / XML / JavaScript / JSON / Python / CSS 等语言的语法着色。
- **彩虹括号 + 括号匹配**：`() [] {}` 按嵌套深度循环配色；SQL 的 `BEGIN/END`、`CASE/END` 以整词栈配对并高亮。
- **混合语言着色**：HTML/ASPX 中的 `<script>`（JS）、`<style>`（CSS）以及 ASPX 的 `<% %>` 服务端块会被正确识别并分别着色。
- **多标签 + 单实例**：可同时打开多个文件，重复打开文件会聚焦到已存在的标签；通过 WM_COPYDATA 实现单实例。
- **左侧文件夹浏览器**：「打开文件夹」后在左侧像 VS Code 资源管理器一样浏览目录，点击文件即以新标签打开，当前文件高亮显示。
- **查找**：自绘查找条，支持上一项 / 下一项，回车跳转、Esc 关闭。
- **轻量编辑**：可直接修改文本并保存，自动识别并按原编码（UTF-8 / UTF-8 BOM / UTF-16 / ANSI-GBK）写回，避免破坏文件编码。
- **深浅主题**：内置 One Dark Pro 风格深色与亮色主题，一键切换。
- **运行时图标**：窗口图标为程序化超采样绘制的 “LR” 标识，任意显示尺寸均清晰。

## 🚀 编译（Windows）

需要 **MinGW-w64**（g++ 支持即可，建议 GCC 16.x）。在项目目录下执行：

```bash
g++ -std=c++17 -mwindows -municode -O2 -s -static -static-libgcc -static-libstdc++ \
    -o LiteReader.exe LiteReader.cpp \
    -lcomctl32 -lcomdlg32 -lshell32 -luser32 -lgdi32 -ladvapi32 -lole32
```

参数说明：

- `-mwindows`：生成 GUI 程序（无控制台窗口）。
- `-municode`：使用宽字符（Unicode）Windows API。
- `-O2 -s`：开启优化并剥离符号，进一步减小体积。
- `-static` / `-static-libgcc` / `-static-libstdc++`：静态链接运行时，生成的 `LiteReader.exe` 可独立运行，无需额外 DLL。
- 链接库：`ole32`（COM，用于文件夹对话框）、`shell32`/`comdlg32`（文件/文件夹选择）、`gdi32`/`user32`（界面绘制与消息）。

编译成功后得到 `LiteReader.exe`。

## 📖 使用说明

### 打开文件 / 文件夹

- **打开文件**：菜单「文件 → 打开」或快捷键 `Ctrl+O`，所选文件在新标签中打开。
- **打开文件夹**：菜单「文件 → 打开文件夹...」或 `Ctrl+Shift+O`，在左侧文件树中浏览；点击任意文件即以新标签打开。
- **关闭文件夹**：菜单「文件 → 关闭文件夹」或点击侧栏头部的 `×`。
- 也可直接将文件拖入窗口打开。

### 编辑与保存

- 直接输入、退格、删除、回车、Tab 即可编辑。
- **保存**：`Ctrl+S`（无路径时弹出“另存为”）。
- 修改后标题栏会显示 ` *` 标记。

### 查找

- `Ctrl+F` 打开查找条，输入关键字后：
  - `回车` / `下一项`：跳到下一个匹配；
  - `Shift+回车` / `上一项`：跳到上一个匹配；
  - `F3`：重复上次查找；
  - `Esc`：关闭查找条。

### 选择

- 鼠标拖拽选择；双击单词高亮该词所有出现位置。
- `Ctrl+A`：全选。
- `Ctrl+C`：复制选中文本。

### 标签管理

- `Ctrl+W`：关闭当前标签。
- `Ctrl+Tab` / `Ctrl+Shift+Tab`：在标签间切换。

### 外观

- **明暗主题**：菜单「视图 → 明暗主题」一键切换。
- **语言**：菜单「视图 → 语言」手动指定高亮语言（默认 `auto` 按扩展名自动识别）。

## 🧩 技术说明

- **纯 Win32 + GDI**：界面全部自绘（标签栏、行号区、查找条、左侧文件树、滚动条），不依赖任何 UI 框架或原生控件，保证零依赖与极小体积。
- **单文件架构**：所有逻辑集中于 `LiteReader.cpp`，方便阅读、修改与移植。
- **全局视图状态模型**：每个标签以 `Doc` 快照保存/恢复编辑状态（文本、光标、滚动、选区、编码、主题无关），切换标签无感知。
- **多选编码**：加载时自动识别 UTF-8 / UTF-8 BOM / UTF-16 LE/BE / ANSI(GBK)，保存时按原编码回写。
